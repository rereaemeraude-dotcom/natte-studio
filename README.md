# Natté Studio

A static booking/service website for a fictional afro hair braiding studio — signature styles, pricing, and an appointment request form (opens the visitor's email client, pre-filled, sent to the studio's inbox).

Live at: https://rereaemeraude-dotcom.github.io/natte-studio/

## Structure

Single static page: `index.html` (all CSS/JS inline, no build step).

## Deploy

Served via GitHub Pages from the `main` branch. Push to `main` to update the live site.
